## 3. 自动化边界说明（需人工测试）

以下项目依赖真实登录态/真实链接/视觉渲染，无法在本地自动化完成，按规范标注待线上人工验证：

| # | 测试项 | 操作步骤 | 期望结果 | 为何不能自动化 | 执行人 | 状态 |
|---|---|---|---|---|---|---|
| M1 | 有效链接分享页渲染 | 管理员创建链接 → 无痕窗口打开 `/share/<token>` | 免登录看到标题/7字段 KPI/明细表 | 需真实 token + 真实报表数据 | 用户 | ⏳ 待验证 |
| M2 | admin JWT CRUD 端到端 | 登录 admin → 访问链接管理页 → 创建/停止/删除/复制 | 列表实时反映状态，URL 可复制 | 需真实 admin 登录会话签发 JWT | 用户 | ⏳ 待验证 |
| M3 | 失效链接友好提示 | 打开已停止/已过期/不存在的链接 | 分别显示对应友好页 | 需真实链接状态 | 用户 | ⏳ 待验证 |
| M4 | 直达管理页路由 | 已登录 admin 浏览器输入 `/admin/access-links` | 直接进入管理页 | 需真实登录态 + 域名路由 | 用户 | ⏳ 待验证 |
| M5 | 视觉渲染与响应式 | 桌面/移动端查看分享页与管理页 | 品牌色正确、无错位 | 浏览器视觉渲染 | 用户 | ⏳ 待验证 |

> M2 同时关闭第 1 批遗留项「真实 admin JWT 端到端」——第 1 批的集成测试用 mock JWT 已覆盖路由逻辑，但真实签名校验必须线上实测。
